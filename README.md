# Tour and Travel Agency Management System

A **Tour and Travel Agency Management System** developed using **C# and MySQL**. The system is designed to simplify the management of tour packages, customers, administrators, and tour guides through a centralized platform.

## Project Overview

The system allows customers to explore available tour packages and view detailed information such as destination, travel plans, package descriptions, images, and other relevant details. Customers can select and enroll in their preferred tour packages.

The system also provides a dedicated **Admin Dashboard**, where administrators can manage tour packages and monitor customer enrollments. Admins can view which customers have enrolled in which packages and manage overall tour-related activities.

A separate **Tour Guide Portal** is also included. Tour guides can log in to the system and view their assigned duties, scheduled tour dates, and other relevant tour information.

## Key Features

* 👤 **Customer Management**

  * Customer registration and login
  * Browse available tour packages
  * View detailed package information
  * View destination and package images
  * Enroll in selected tour packages

* 🧳 **Tour Package Management**

  * Add, update, and manage tour packages
  * Store package descriptions and images
  * Manage destinations and travel information

* 📊 **Admin Dashboard**

  * Monitor customer enrollments
  * View customer and package information
  * Manage tour packages
  * Monitor overall tour activities

* 🧑‍💼 **Tour Guide Portal**

  * Tour guide login
  * View assigned tour duties
  * Check duty dates and schedules
  * Access relevant tour and assignment information

## Technology Stack

* **Programming Language:** C#
* **Database:** MySQL
* **Application Type:** Tour & Travel Management System

## Main Objective

The main objective of this project is to provide a centralized system for managing tour and travel operations. It reduces manual management, improves communication between customers, administrators, and tour guides, and makes tour package enrollment and scheduling more organized and efficient.

## System Roles

The system consists of three main user roles:

1. **Customer** – Browses packages, views package details, and enrolls in tours.
2. **Admin** – Manages packages and monitors customer enrollments and tour activities.
3. **Tour Guide** – Views assigned tours, duty dates, and schedules.

## Project Highlights

This project demonstrates the implementation of a role-based tour management system with customer enrollment, package management, administrative monitoring, and tour guide scheduling using **C# and MySQL**.
